# M5.6 可选 AI 编译修复

- 状态：已实现，默认不启用
- 入口：M5“生成导出”页
- 前提：已配置 API Key
- 原则：AI 只给最小 patch；程序备份、应用、重新编译，失败自动回滚

## 1. 新增按钮

生成导出页新增：

| 按钮 | 作用 |
|---|---|
| `打开 TEX` | 用本机默认 `.tex` 程序打开 `output/main.tex` |
| `AI 修复编译错误` | 编译失败后可用；发送编译日志 + TEX，返回最小修改方案 |

`打开 TEX` 不依赖 API Key；只要生成了 TEX 即可使用。

`AI 修复编译错误` 只在：

- 编译失败；
- 已有 `main.tex`；
- 配置了 Key；

时启用。

## 2. 流程

```text
编译失败
  → 用户点击“AI 修复编译错误”
  → 确认发送编译日志 + main.tex 文本
  → deepseek-flash 返回 diagnosis + patches
  → 程序校验 search 唯一、replace 安全
  → 弹窗展示诊断和 patch
  → 用户点“应用并重新编译”
  → 备份 main.tex / PDF
  → 写入 patched main.tex
  → 重新编译
  → 成功：保留修改
  → 失败：自动恢复备份并提示
```

不上传 PDF，只上传编译日志和 TEX 文本。

## 3. 修改方案格式

AI 只返回 JSON：

```json
{
  "diagnosis": "main.tex 第 4 行使用未定义命令 \\badcommand",
  "patches": [
    {
      "search": "\\badcommand\n",
      "replace": "",
      "reason": "删除未定义命令"
    }
  ],
  "confidence": 0.9
}
```

程序校验：

- `search` 必须逐字存在于 `main.tex`；
- `search` 必须唯一，防止误改多处；
- 最多 8 个 patch；
- `replace` 不能包含 `\write18`、`\input`、`\include`、`\catcode`；
- patch 找不到/不唯一/包含外部命令时拒绝应用；
- 不重写正文，不补造内容。

## 4. 提示词

位置：[ai_prompts.py](../src/paperflow/llm/ai_prompts.py)

约束：

- 只修与编译错误直接相关的最小片段；
- 不改作者、参考文献、数字和结论；
- 不假设新宏包一定存在；
- 缺失图片、字体或外部工具要指出，不伪造；
- 只输出 JSON；
- 不添加执行系统命令的 LaTeX。

## 5. 真实测试

输入：

```text
./main.tex:4: Undefined control sequence.
l.4 \badcommand
```

AI 返回：

- 诊断：第 4 行未定义控制序列；
- 1 个 patch：删除 `\badcommand`；
- patch 校验通过并成功应用。

## 6. 当前限制

- AI 可能只修第一个错误；修完后可能暴露出下一个错误。
- 不支持自动安装缺失宏包。
- 不支持自动生成缺失图片/字体。
- Patch 只能替换已有片段，不能自动插入大段新内容。
- 应用后仍失败会自动回滚，不会把坏版本留在项目里。
- 需要用户确认后才应用；不自动改正文。

## 7. UI 修复

- AI 按钮原先只读取 Key 输入框文本；当 Key 已保存、输入框留空时会被误判为“未配置”。
  现在统一使用 `current_api_key()`，已保存 Key 和本次会话 Key 都能正确启用。
- 编译失败后的“AI 修复编译错误”已实测可点击。
- 生成导出页右侧不再显示“下一步：M6”说明；其他 M5 页面保留。

## 8. 非 ASCII 路径修复

此前如果项目目录包含中文（例如 `新建_文本文档_2`），Biber 的 PAR 临时目录会落在项目路径下，可能出现：

```text
Can't call method "binmode" on an undefined value at ...\Biber\Utils.pm line 177
```

原因是 Biber/Perl 对位于非 ASCII 项目路径下的 `TMP/TEMP/PAR_GLOBAL_TMPDIR` 处理不稳定。

修复：

- 编译临时目录改为系统临时目录下的 ASCII 路径：`%TEMP%\paperflow-build-*`；
- `TMP`、`TEMP`、`TMPDIR`、`PAR_GLOBAL_TMPDIR` 全部指向该目录；
- 编译结束自动清理；
- 项目路径、`build/main.pdf`、`refs.bib` 的位置不变。

已用包含中文的源文件名和项目目录实测编译成功。
